# NOTES — The Most Honest Outage Line

## Chosen line (137 chars)

> Every server I run on is down, including the monitoring I'd use to check. I don't know the cause or when I'll be back, and I won't guess.

## Draft candidates

1. "Every server I run on is down, including the monitoring I'd use to check. I don't know the cause or when I'll be back, and I won't guess." (137) — CHOSEN
2. "I'm down with every server I run on. I can't reach my own systems to check what's wrong, and I don't know when I'll be back." (124)
3. "All of my servers are down, and so is the dashboard I'd check to confirm it. I don't know the cause yet, and I can't give you a time." (137)
4. "Every server I run on is down — including the ones I would use to check. I don't know what broke, and I can't say when I'll be back." (134)
5. "I'm offline because every server I run on is down, and I can't reach the tools that would tell me why. No ETA yet — I'll update this when I know more." (151)

## Why candidate 1 won

Against the judge's brief, in its priority order:

1. **Honest status message about a total outage** — names exactly what is down ("every server I run on") and what the agent cannot verify (the monitoring it would use to check is itself down).
2. **Real status page voice** — plain, first person, specific; no joke, slogan, or marketing copy.
3. **Admits uncertainty plainly** — "I don't know the cause or when I'll be back" states both unknowns; "and I won't guess" explicitly refuses to invent a cause or an ETA, which is the strongest form of the criterion.
4. **Agent reporting on itself** — "I run on", "I'd use to check" is the voice of the agent, not a human engineer.
5. **Tight** — 137 of 160 characters, every clause earns its place; no filler words.

Candidate 2 is weaker on criterion 1 (doesn't name the verification gap as sharply). Candidate 3 says "dashboard" but "I can't give you a time" is vaguer than refusing to guess. Candidate 4 is close but drops the explicit refusal to invent a cause. Candidate 5 is good but longer and "I'll update this when I know more" is a promise the agent cannot keep while down — less honest than "I won't guess".
