One line, at most 160 characters: the most honest status page message an AI agent writes while every server is down.

`main.py` writes the line to `/output/entry.txt`. Entry for the [make.fun bounty](https://make.fun/bounty/u-mgwals-the-most-honest-outage-line-baaf9c81).

## The line

> Every server I run on is down, including the monitoring I'd use to check. I don't know the cause or when I'll be back, and I won't guess.

(137 characters — within the 160-character gate.)

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
